The Ship Kit v1.0.13

Ship Kit setup guide (about 10 minutes)

Copy the claude/ or cursor/ files (or both) into your app, restart your tool, then run the security audit. Then work the launch checklist and run the pre-launch job.

Claude Code: supported, but not yet tested live on Claude Code. The Cursor version has been tested live. If something behaves differently in Claude Code, tell us and we will fix it.

Do not have the kit yet? The Ship Kit is on Whop. The launch checklist is free.

What each file is for

CLAUDE.md (Claude Code)
Project memory at your app's top folder. Claude Code reads it in every chat. The Ship Kit block holds the safety and voice rules, between the lines <!-- Ship Kit start --> and <!-- Ship Kit end -->.
.claude/agents/ and .claude/skills/ (Claude Code)
The seven jobs: security-audit, supabase-rls, stripe-payments, auth-review, pre-launch, performance-seo, error-logging. Agents run when you ask for them by name. Skills give you the slash commands, like /security-audit.
.cursor/rules/*.mdc (Cursor)
Eight rule files. ship-kit-core.mdc is always on and holds the safety and voice rules. The other seven are the jobs, loaded when you @-mention them, like @ship-kit-security.
AGENTS.md (Cursor)
Plain markdown instructions at your app's top folder. Same idea as CLAUDE.md, with the same marked Ship Kit block.

Where the pre-launch job fits

Order: install, run the security audit, fix Critical items, walk the launch checklist, then run /pre-launch (Claude Code) or @ship-kit-prelaunch (Cursor). Ship only when blockers are gone.

The full guide

You do not need to be a developer. Follow the path that matches your tool.

This kit is a checklist and audit aid. It is not a security guarantee, penetration test, or legal advice. You are responsible for your app, your keys, and your launch.

Before you start

  • Your app folder is open on your computer.
  • You can copy and paste files (Finder, Explorer, or your editor).
  • Optional: git commit your current work so you can undo.

Path A: Claude Code

  1. Unzip The Ship Kit. It unpacks into a ship-kit/ folder.
  2. Open the claude/ folder inside the kit.
  3. Copy CLAUDE.md into your app's top folder. If you already have CLAUDE.md, open both and keep your notes, then paste in the whole Ship Kit block: everything from the line <!-- Ship Kit start --> to the line <!-- Ship Kit end -->, both of those lines included. Paste it as one piece, outside your own notes. If your file has the marker lines, first delete the old marked block (from <!-- Ship Kit start --> to <!-- Ship Kit end -->), then paste the new one. If it has no marker lines (v1.0.7 or older), first delete the old text from the heading # Project instructions (Real App Club Ship Kit) down to and including the line "This kit is a checklist and audit aid. It is not a security guarantee, penetration test, or legal advice. You are responsible for your app, your keys, and your launch." (the same steps as README, How to roll back, step 3), then paste the new block. If you cannot find the heading or that last line (for example because you pasted only part of the text), open the kit's own file and remove the matching lines by comparing, or restore the file from your git history.
  4. Copy the whole .claude folder into your app's top folder (so you get .claude/agents and .claude/skills).
  5. Quit Claude Code fully, then open your app again with Claude Code.
  6. In chat, say: Use the security-audit agent on this project
    Or type: /security-audit
  7. Read the report. Fix Critical items before you launch.

Other jobs: /supabase-rls, /stripe-payments, /auth-review, /pre-launch, /performance-seo, /error-logging.

Path B: Cursor

  1. Unzip The Ship Kit.
  2. Open the cursor/ folder inside the kit.
  3. Copy AGENTS.md into your app's top folder. If you already have AGENTS.md, keep your notes and paste in the whole Ship Kit block: everything from the line <!-- Ship Kit start --> to the line <!-- Ship Kit end -->, both of those lines included. If your file has the marker lines, first delete the old marked block (from <!-- Ship Kit start --> to <!-- Ship Kit end -->), then paste the new one. If it has no marker lines (v1.0.7 or older), first delete the old text from the heading # Agent instructions (Real App Club Ship Kit) down to and including the line "This kit is a checklist and audit aid. It is not a security guarantee, penetration test, or legal advice. You are responsible for your app, your keys, and your launch." (the same steps as README, How to roll back, step 3), then paste the new block. If you cannot find the heading or that last line (for example because you pasted only part of the text), open the kit's own file and remove the matching lines by comparing, or restore the file from your git history.
  4. Copy .cursor/rules into your app so the .mdc files live at .cursor/rules/. That is 8 files: ship-kit-core.mdc (always on) plus 7 job rules.
  5. In Cursor, open Customize → Rules and confirm the Ship Kit rules appear.
  6. In Agent chat, run one job at a time. Ask in a sentence, and @-mention the rule so it loads even if Cursor does not pick it from the description: - Security: Run a security audit using the Ship Kit security rule or @ship-kit-security - Supabase RLS: @ship-kit-supabase-rls - Stripe: @ship-kit-stripe - Auth: @ship-kit-auth - Pre-launch: @ship-kit-prelaunch - Performance and SEO: @ship-kit-performance-seo - Errors and logging: @ship-kit-error-logging
  7. In Customize, then Rules, ship-kit-core shows as Always: it holds the safety and voice rules and loads in every chat. The other seven rules (the @ names above) should show Apply Intelligently. They have a description and no file globs. Do not add globs. A glob would hide the rule until a matching file is open, and the auth, SEO, and error rules are most useful when those files are missing.
  8. Fix Critical items before you launch.

Path C: Lovable or Bolt

You cannot install Claude subagents there. Use the prompt pack instead:

  1. Open prompts/hardening-lovable-bolt.md.
  2. Copy the Security audit prompt into Lovable/Bolt chat.
  3. Paste follow-ups for RLS, Stripe, and auth as needed.
  4. Still walk the launch checklist by hand.

After the audit

  1. Open checklists/launch-checklist.md (or the PDF).
  2. Check every box you can.
  3. Run /pre-launch (Claude) or @-mention @ship-kit-prelaunch (Cursor). The other Cursor jobs use the same @ names as in Path B.
  4. Ship only when blockers are gone.

If something does not load

  • Claude: new .claude/agents folder often needs a full restart.
  • Cursor: rule files must end in .mdc (not .md).
  • You merged wrong: compare with the kit's clean copy.

What this kit does not do

  • It does not log into your Stripe or Supabase dashboard for you.
  • It does not replace a professional pentest for high-risk apps (health, finance at scale).
  • It does not publish your app.
